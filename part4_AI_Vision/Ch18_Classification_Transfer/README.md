# 第 18 章　影像分類與遷移學習

`[基礎]`　建議時數 4 小時　｜　對應舊章：**無**（補課綱缺口 B7）

## 學習目標

1. 說出遷移學習的三種策略，以及各自什麼時候該用
2. **不做任何訓練**就完成一次遷移學習（特徵抽取 + 淺層分類器）
3. **量測**該從哪一層抽特徵，而不是憑直覺選
4. 說出為什麼「ImageNet 分數越高的骨幹，遷移特徵越好」是錯的
5. 讀懂 `trainingOptions` 的關鍵設定，並說出設錯的症狀
6. 用三種可解釋性方法交叉驗證一個分類決定

> **關於訓練：本章的微調段落預設「只組好程式碼、不執行訓練」。**
> 本章**所有的量化結論都來自特徵抽取路線**（策略一），
> 那條路線幾秒鐘跑完，而且是真實可驗證的數字。

> **關於數字：本章刻意不把準確率寫死在敘述裡。**
> 第 6.1 節量到「同一份資料重跑五次，準確率的全距是 2–5 個百分點」，
> 所以你在自己機器上跑出來的數字**一定和教材不同**。
> 敘述引用的是某次執行的範例，重點在**效應量的等級**。

## 本章最重要的四課

### 1. 不訓練也能做遷移學習（第 4 節）

`resnet18` 的 `pool5` 特徵 + `fitcecoc`，DigitDataset 每類 40 訓練／20 測試：
**準確率約 0.85，抽特徵幾秒、擬合分類器 1 秒，一次梯度都沒算。**

策略一的優點常被低估：不需要 GPU、訓練是**凸最佳化**（不會發散）、
樣本少時常常**贏過**微調。

但 85% 要放在脈絡裡：**專為 MNIST 設計的小 CNN 從零訓練能到 99%+。**
ImageNet 特徵在 28×28 手寫數字上只能到這裡，
**因為兩個領域差得很遠——遷移學習不是魔法。**

### 2. 特徵層越深越好，而「遠領域用淺層」是錯的（第 5 節）

| 層 | 維度 | 準確率（某次執行） |
|---|---|---|
| `res2b_relu` | 64 | 0.21 |
| `res3b_relu` | 128 | 0.20 |
| `res4b_relu` | 256 | 0.55 |
| `res5b_relu` | 512 | **0.85** |
| `pool5` | 512 | **0.83** |

常見說法是「領域差很遠就用淺層，因為淺層特徵比較通用」。
**這裡差了 65 個百分點，方向完全相反。**

那個直覺混淆了兩件事：淺層特徵比較**通用**（對），
淺層特徵比較**有用**（不一定）。手寫數字全部都是黑白邊緣，
而 `res2b_relu` 編碼的正是邊緣與色塊——**沒有判別力**。

### 3. 先量雜訊，再下結論（第 6.1 節 — 本章最重要的方法論）

**同一份資料、同一個切分、同一段程式碼，重跑五次：**

| 執行 | 五次的準確率 | 標準差 | 全距 |
|---|---|---|---|
| A | 0.810／0.855／0.845／0.830／0.860 | 0.0203 | **0.050** |
| B | 0.830／0.850／0.845／0.835／0.840 | 0.0079 | **0.020** |

原因有兩個疊在一起：
1. **GPU 推論不是逐位元決定性的**（cuDNN 演算法選擇 + 浮點加法不符合結合律）
2. **分類器把微小差異放大成離散的翻面**（§5.1 量到特徵差 1.4e-06）

| 變異來源 | 標準差 |
|---|---|
| 同一切分重跑 | 0.0203 |
| 換切分 | **0.0344** |
| 二項理論下限（p=0.86, n=200） | 0.0248 |

**要可靠分辨 1 個百分點，測試集需要約 5,000 張影像。我們有 200 張。**

而四個骨幹的差距只有 1–6 個百分點 → **用這個測試集分辨不出它們**。

> **我第一版的教材就是在這裡出錯的。** 我看到某次執行 `mobilenetv2` 拿 0.925，
> 寫下「最小的網路贏了」還替它編了一套說法，**第二次執行就推翻了它**。
> 那個錯誤留在教材裡，因為它比正確答案更有教學價值。

### 4. `pool5` 和 `res5b_relu` 數學上相同，數值上不同（第 5.1 節）

`pool5` 就是 `res5b_relu` 的全域平均池化，教材的特徵抽取做的是同一件事。
**但 `isequal` 回傳 false，最大絕對差 1.4e-06**（`single` 精度下累加順序不同）。
那個差異足以讓邊界樣本翻面，於是準確率差 0.5 個百分點。

> **報告一個 0.5 個百分點的「改善」時，你可能只是報告了一次浮點捨入。**

原本想把「兩者準確率相同」當成自我檢查，實測後改成
**「兩者的特徵差異應在 1e-5 以內」**——
檢查數值本身，不要檢查經過分類器放大的下游指標。

## 練習重點

- **練習 1**：領域距離。兩個二分類任務都拿到 1.0000 → **天花板效應**，
  這個實驗答不了原本的問題。並指出 $p=1$ 時二項 CI 退化成 0 是假的。
- **練習 2**：**配對比較**。同一批切分評估所有骨幹，切分變異被抵消。
  `mobilenetv2` − `resnet18` = +0.0667、t = 3.02——
  **但自由度只有 2，臨界值是 4.30，所以 p ≈ 0.094，還是不能下結論。**
  （我第一版在這裡也寫錯了：憑印象寫「t > 2.5 就可信」，那是大樣本直覺。）
- **練習 3**：資料量曲線。5 張 → 0.59、20 張 → 0.81、100 張 → 0.93，
  **在 100 張還沒飽和**。每類 5 張時的標準差比 20 張時大 16 倍——
  小資料的實驗最需要重複，而那正是最常被省略的時候。
- **練習 4**：可解釋性。**先想清楚你在解釋哪個模型**——
  `gradCAM` 解釋的是 ImageNet 分類頭，不是你接上去的 SVM。
  解答用手作的遮擋敏感度解釋 SVM，並說明為什麼這**不能證明因果**。
- **練習 5**：微調（預設不執行，`DO_TRAIN=false`）。含學習率調大 100 倍的症狀。
- **練習 6**：類內／類間距離比值。`res2b_relu` **1.33 > 1**
  （同類影像平均比不同類還遠），`pool5` 0.91。**在原始空間算，不要在降維後算。**
- **加分題**：線性 0.810 / RBF 0.855 / 淺層網路 0.865。
  差距 5.5 個百分點**剛好落在雜訊上緣**，所以是暗示不是證據。
  並回答「什麼時候必須微調而不是換分類器」。

## R2026a 注意事項

- **`imagePretrainedNetwork(name, NumClasses=n)` 只能有一個輸出引數**，
  否則報「For transfer learning workflows... must have one output argument only」。
- **ViT 的函式是 `visionTransformer`，不是 `vit`。**
  `which("vit")` 會找到 Communications Toolbox 的 `comm/commmex/vit.mexw64`
  （Viterbi 解碼器）——**名稱衝突**。`imagePretrainedNetwork` 不支援任何 ViT 名稱。
- 部分骨幹需要各自的支援包（例如 `googlenet`）。
- 灰階影像餵給 ImageNet 網路要先 `repmat(I,1,1,3)`。
- **不同骨幹的池化層名稱完全不同**（`pool5`／`global_average_pooling2d_1`／
  `avg_pool`／`avg1`）。用層的**類別**去找，不要寫死名字。
- `gradCAM` 回傳的圖已放大到輸入尺寸，**有效解析度仍是最後卷積層的 7×7**。
- **每個載入的網路都佔顯示記憶體，掃描骨幹時用完要 `clear`**
  （第 17 章 §10.1 量到不清會讓推論安靜地慢好幾倍）。
- **單張影像不要繞 `arrayDatastore`**：`OutputType="cell"` 會讓 transform
  收到 cell，`imresize` 報一個指不出原因的錯。直接呼叫 `predict` 最單純。
