## 這一章的四個實測結果

**1. 週期性條紋：頻域完勝（第 4 節）**

| 方法 | PSNR |
|---|---|
| 加入條紋（未處理） | 15.52 dB |
| NLM | 15.53 dB |
| 中值 5×5 | 17.74 dB |
| 高斯 σ=2 | 20.79 dB |
| **Notch 濾波** | **25.96 dB** |

空間域濾波器全部失效，因為它們假設「雜訊是局部的、隨機的」，
而週期性條紋是**全域的、有結構的**。NLM 幾乎毫無幫助（+0.01 dB）。

**2. 卷積定理成立到浮點精度（第 3 節）**

空間域卷積與頻域相乘的最大差異：**7.77e-16**。
注意必須用 `"circular"` 邊界才一致——FFT 隱含假設影像週期重複。

**3. 小波能定位，傅立葉不能（第 5.2 節）**

對「左半平滑、右半銳利」的影像，小波細節能量：
左半 0.0005、右半 0.0745——**相差 160 倍**，清楚指出高頻在右邊。
同一張影像的傅立葉頻譜完全看不出左右差異。

**4. 小波去雜訊在 3 階飽和（練習 4）**

| 階數 | PSNR |
|---|---|
| 1 | 24.11 |
| 2 | 25.18 |
| 3 | 25.33 |
| 4–6 | 25.30–25.32 |

256×256 的影像分解 3 階後近似只剩 38×38，再往下分解的是一張比雜訊尺度
還粗的縮圖——那個尺度上沒有雜訊可去。建議階數 `floor(log2(min(size)))-4`。

## 核心函式

`fft2` `ifft2` `fftshift` `ifftshift` `wavedec2` `waverec2` `appcoef2`
`detcoef2` `wdenoise2` `waveletImageAnalyzer` `dwt2` `idwt2`

## 本章函式

| 檔案 | 用途 |
|---|---|
| `code/ch05_notchFilter.m` | 練習 3 解答：自動偵測並移除週期性干擾。支援彩色（三通道共用同一組峰值以避免色偏），並強制成對處理峰值 |

實測四組不同頻率與方向的干擾，改善都在 10–13 dB，且移除的能量都在 12% 以內。

### 為什麼必須成對挖峰值

實數影像的頻譜共軛對稱。只挖一側時：
- `ifft2` 結果的虛部最大值達 **0.1573**（正常應是 1e-16 等級）
- 條紋**沒有被移除**——剩下的那一半鏡像自己就能合成出實數正弦波

## 練習

五題 + 一題加分題。

- **練習 1** 只給頻譜，要你反推影像內容。訓練「看頻譜」的直覺：
  亮點方向 → 條紋走向；離中心距離 → 頻率高低；多組諧波 → 非正弦波形。
- **練習 2** 量化振鈴：用剖面的二階差分能量。理想濾波器的振鈴來自
  矩形窗的傅立葉轉換是 sinc，而 sinc 有無限延伸的振盪尾巴。
- **練習 5 第 4 題**有個容易搞錯的地方：5000×5000 影像做 101×101 高斯模糊，
  FFT 只比可分離卷積快 1.4 倍（不是壓倒性）。交叉點是 `K = 6·log2(N)`。
  **不要背「大核就用 FFT」**。
- **加分題**同時有條紋與雜訊時，順序有差：

| 順序 | PSNR |
|---|---|
| 先去雜訊再 notch | 23.85 dB |
| **先 notch 再去雜訊** | **25.12 dB** |

原因是去雜訊會讓頻譜中的干擾峰值變寬變矮，更難精準定位。
**通用原則：先處理結構性的問題，再處理隨機性的問題。**
