## 這一章的三個關鍵發現

以下都是教材裡實測出來的，不是引述教科書：

**1. `ClipLimit` 越大，局部對比上升、全域對比下降（第 4.3.1 節）**

同一組影像，兩個指標給出相反結論：全域標準差 72 → 56，局部標準差
0.039 → 0.121。兩個都對，量的是不同的東西。
教訓是：**選錯指標就會得到錯誤結論**——用全域標準差評估 CLAHE，
你會得出「CLAHE 讓對比變差」這種荒謬結果。

**2. 換到 Lab 只調 L 通道，不等於零色相偏移（第 8.4–8.5 節）**

| 做法 | 平均色相偏移 |
|---|---|
| 逐通道 `histeq`（錯誤做法） | 9.9° |
| `lab` + `stretch` | 1.9° |
| `lab` + `clahe` | 4.2° |
| `lab` + `histeq` | **12.2°（比錯誤做法還糟）** |
| `hsv` + 任何方法 | **0°** |

原因是**色域裁切**：改完 L 之後 (L,a,b) 可能落在 sRGB 之外，
`lab2rgb` 裁切回 [0,1]，裁切就改變了通道比例。實測超出色域的通道值佔比：
stretch 5.9%、clahe 7.5%、histeq 13.2%——推出去越多，偏移越大。

HSV 的 V 是 `max(R,G,B)`，調它等於三通道同比例縮放，色相依定義不變
（實測誤差 1.8e-15）。

**3. 增強不會讓分割變好（練習 5）**

用第 02 章的資料集測試「先增強再分割」：

| 前處理 | 正確數 |
|---|---|
| 不處理 | 3/6 |
| `imadjust` | 1/6 |
| `imflatfield` | 2/6 |
| Lab-CLAHE | 0/6 |

全部更糟。因為第 02 章診斷出的失效原因是**色相偏移**，
而點運算調整的是**亮度分布**——修錯了地方，還引入新的失真。

## 練習

五題 + 一題加分題。

- **練習 1** 有個陷阱：題目問「有沒有救不回來的」，答案是**沒有**。
  不要因為被問了就硬指認一張。
- **練習 2** 做出一張真正過曝截斷的影像，用熵與灰階數證明為什麼救不回來——
  讓你有底氣跟人說「請重拍」。
- **加分題**自己用 CDF 實作 `histeq`，證明「點運算就是查表」：
  無論影像多大，真正的運算量永遠是 256 次。
