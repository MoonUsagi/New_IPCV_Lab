# 第 04 章　空間域濾波與雜訊處理

`[基礎]`　建議時數 3 小時　｜　**全新章節**（原教材完全沒有）

## 為什麼要有這一章

原 IPCV_Lab 沒有任何濾波章節——這是影像處理最基本的一課，卻是最大的缺口之一。
點運算（第 03 章）能處理亮度與對比，但**無法處理雜訊**：
雜訊的定義就是「這個像素跟鄰居不一致」，只看單一像素根本分辨不出來。

## 學習目標

1. 說明卷積如何運作，並正確處理邊界
2. 依**雜訊類型**選擇濾波器，而不是每次都用高斯
3. 說明保邊濾波與一般平滑濾波的差別，並用數字證明
4. 在品質與速度之間做出有依據的取捨
5. 用 PSNR／SSIM 量化去雜訊效果，而不是靠肉眼

## 這一章的四個實測發現

**1. 濾波器 × 雜訊類型矩陣（第 4 節）**

| 雜訊 | 最佳濾波器 | 進步 |
|---|---|---|
| 高斯 | NLM | +7.66 dB |
| 椒鹽 | **中值 3×3** | +8.57 dB |
| 斑點 | NLM | +7.63 dB |

中值濾波對椒鹽雜訊比高斯好 3.7 dB；但對高斯雜訊，中值的 SSIM 只有 0.529，
比高斯濾波的 0.688 差很多。**沒有萬用濾波器。**

**2. 雙邊濾波對椒鹽雜訊比不處理還糟（第 4.2 節）**

不處理 18.21 dB → 雙邊濾波 **18.18 dB**。
雙邊濾波的原理是「只平均亮度相近的鄰居」，椒鹽雜訊點跟所有鄰居都差很遠，
於是它判定「這是邊緣，要保留」——**認真地把雜訊保護了起來**。

教訓：**濾波器的設計假設決定了它的適用範圍**。用之前先問，我的資料符合它的假設嗎？

**3. 保邊濾波真的保邊（第 5.1 節）**

取原圖梯度最強的前 10% 像素當「邊緣」，量測濾波後保留多少梯度：

| 類型 | 邊緣梯度保留 |
|---|---|
| 均值 5×5 | 36.6% |
| 高斯 σ=1.5 | 40.9% |
| 導引 | 86.7% |
| NLM | 87.8% |
| 雙邊 | 96.7% |
| 非等向擴散 | 97.4% |

**4. `imfilter` 比 `imgaussfilt` 快（第 2.4 節）**

與常見說法相反。`imfilter` 本身就會偵測可分離核，而 `imgaussfilt` 每次呼叫
都要重建核並驗證引數。那為什麼還要用 `imgaussfilt`？因為它讓你只指定 sigma，
核大小由它正確決定——避免 `fspecial("gaussian", 3, 3)` 這種把高斯尾巴切掉的錯誤。

### `ch04_autoDenoise` 的判斷依據為什麼要改兩次

第一版用「等於 0 或 1 的像素比例」判斷椒鹽雜訊。**失敗了**——
`imnoise` 加高斯雜訊會裁切到 [0,1]，cameraman 的暗大衣與亮天空產生了 5.9%
的極值像素，被誤判成椒鹽雜訊。

修正後要求極值像素同時**明顯偏離局部中值**。實測分離度：

| 影像 | 孤立極值比 |
|---|---|
| 乾淨 | 0.00% |
| 高斯雜訊 | 0.05–0.35% |
| 斑點 | 0.16% |
| 椒鹽（密度 0.01） | 0.78% |
| 椒鹽（密度 0.03） | 2.37% |

門檻 0.5% 可以乾淨分開。**你的第一個判斷依據通常是錯的，要用反例測試它。**

## 練習

五題 + 一題加分題。

- **練習 1** 給三張打亂順序、不說明雜訊類型的影像，要你診斷。
  解答示範用三個特徵判斷：孤立極值比、雜訊分布直方圖、與亮度的相關性
  （斑點雜訊是乘性的，殘差與亮度正相關）。
- **練習 2** 畫出「失去的細節」與「殘留的雜訊」兩條誤差曲線，
  看出它們如何此消彼長——**幾乎所有參數都是在兩種相反的誤差之間找平衡點**。
- **練習 5** 延續第 03 章練習 5，結論更完整：

| 前處理 | 正確數 |
|---|---|
| 不處理 | 3/6 |
| 高斯 σ=1 | 2/6 |
| NLM | 2/6 |
| **`ch04_autoDenoise`** | **4/6** |

六張影像裡只有一張有雜訊。一律濾波等於「為了救一張，犧牲另外五張」。
`autoDenoise` 贏不是因為濾波器比較好，而是因為它**知道什麼時候不該動手**。

- **加分題**用 `im2col` 自己實作中值濾波，並算出它的記憶體代價：
  1024×1024 影像展開後佔 72 MB（原影像 8 MB），放大 9 倍。
  5×5 核放大 25 倍，7×7 放大 49 倍——這就是為什麼要用內建函式。
