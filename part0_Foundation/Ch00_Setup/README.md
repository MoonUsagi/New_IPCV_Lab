# 第 00 章　課程地圖、環境建置與資料準備

`[基礎]`　建議時數 2 小時　｜　新增章節（原教材沒有）

## 學習目標

1. 確認自己的 MATLAB 環境是否足以進行所選的學習路徑
2. 取得課程所需的全部資料集
3. 說明本課程的「五步驟工作流」，並知道每一章會如何依循它
4. 在遇到環境問題時，自行定位是缺工具箱、缺支援包、還是缺 GPU 記憶體

## 為什麼要有這一章

原教材沒有環境章節，開課第一小時通常全部耗在裝環境上，而且每個學員缺的
東西不一樣。這一章把環境檢查自動化，並讓學員在開課**前**就能自行完成。

## 內容

| 節 | 主題 |
|---|---|
| 1 | 這套課程在教什麼（課程地圖） |
| 2 | 選一條學習路徑 |
| 3 | 設定課程路徑（`ipcvSetup`） |
| 4 | 檢查環境（`checkEnvironment`，含 HTML 報告） |
| 5 | GPU 與記憶體 |
| 6 | 取得課程資料 |
| 7 | 每一章長什麼樣子 |
| 8 | **五步驟工作流**（貫穿全課程的方法論） |
| 9 | 版本策略與相容性（含 `findLegacyAPI` 掃描） |
| 10 | 常見問題排除 |

## 核心工具

| 函式 | 用途 |
|---|---|
| `ipcvSetup` | 設定課程搜尋路徑 |
| `checkEnvironment` | 比對需求與已安裝項目，可輸出 HTML 報告 |
| `courseRequirements` | 各章需求清單（資料表，新增章節時只改這裡） |
| `downloadCourseData` | 依 `datalist.json` 下載資料集，含快取 |
| `findLegacyAPI` | 掃描已移除／過時的 MATLAB 函式 |

## 企業內訓用法

開課前請每位學員執行：

```matlab
cd 課程根目錄
ipcvSetup
checkEnvironment(Chapters=<該梯次的路徑>, ReportFile="我的名字_env.html")
```

把產生的 HTML 回傳給講師，開課前就能確認全班環境一致，不會有人在第一小時
才發現少裝支援包。

## 環境需求

僅需 MATLAB R2026a 與 Image Processing Toolbox。本章本身不需要任何支援包
——它的工作就是告訴你**後面的章節**需要什麼。

## 練習

`exercise/Ch00_Exercise.m` 三題 + 一題加分題，解答在 `Ch00_Solution.m`。

加分題要學員查 Release Notes、自行擴充 `findLegacyAPI` 的規則表——目的是
養成「新版出來就去看 Release Notes」的習慣，因為這套教材的長期維護就靠它。
